# grow-me 需求生长树 · 视觉规范（基准：v7.html）

## 颜色
- 纸底 #efe9dc，叠一层细噪点纹理（feTurbulence，透明度 0.09）
- 墨色（树干、枝、暗芽）#2f2c26；正文 #2b2a26；次要文字 #8a8373 / #9a917e
- 每轮一块晕染色（依次）：#7fa392 #c9a36a #8ea1b8 #a7a886 #c29a8c #86a4a4，透明度 0.32，经过位移和模糊处理
- 花瓣 #f7f2e8，描边 #8b8270，花心 #c08a4a；黄叶 #c9a25e；果 #b5654a
- 主按钮 #3a372f 底，文字用纸色

## 树干
- 不画等宽线条，画填充的锥形路径：底宽 34−1.3×当前轮次，顶宽取 max(5, 底宽×0.3)，沿途宽度有约 ±12% 的起伏
- 根部向两侧长出两条根须
- 光树干（第一根枝以下）高 190（viewBox 单位，画布为 1000×900）
- 第 r 轮的树干段高 = clamp(40+12n, 70, 130)，n 为这一轮的题数
- 树干整体倾斜并弯曲：x = BX + 0.07·h + 16·sin(h/150)，h 为离地高度

## 枝
- 主枝（没有依赖的题）挂在本轮那段树干上，挂点在这段高度的 30%–75% 之间，左右交替
- 主枝长 = clamp(100+20n−6r, 130, 240) × (0.85–1.15)；角度在基准角上加 ±11°
- 子枝从父枝 70%–80% 的位置长出，长度为父枝的 0.45–0.70（最短 62），角度加 ±13°
- 枝宽：主枝起点 max(5, 10.5−0.9r)；子枝起点为父枝的 0.45 倍（最小 1.6）；末梢的枝细到 1
- 弯曲：二次曲线，取 16 个采样点，每点按 sin 包络加 ±2.5 的垂直抖动
- 随机种子由持久的需求标识 session_id 与节点 id 共同生成（对 JSON 数组做 FNV-1a 哈希，再用 J(i)=fract(sin(i·127.1+311.7)·43758.5453) 取样）。新需求分配唯一 session_id，恢复、刷新、重播和改答案沿用它；不使用时间戳。相同题目与依赖可因需求不同而长成不同树形，同一需求的几何保持稳定
- 避让最多尝试 192 个确定性候选，每次都受上述角度、长度和挂点范围约束；优先保留节点间距至少 25 的候选，否则选间距最大的候选。控制点横向弯曲因子为 10–32，向上抬升为 10–24；避让不能越界放大这些参数。28 题回归同时检查实体不重叠和实际点击
- 小枝：每根枝的 6/16 和 11/16 处各长一根侧枝（长 10–24）；末梢的枝在顶端再分两根细杈
- 墨迹：路径加轻微位移（ink，scale 2.2）；粗枝上叠一层干笔纹理，透明度 0.22，要淡，不能有毛刺感

## 花 / 叶 / 果
- 待答：暗芽，墨色圆点 r 2.6
- 已答：五瓣小白花（每瓣 r 2.9，距中心 3.4）加花心
- needs_review：一片顺着枝方向的黄叶（椭圆，9×3.6），透明度 0.75
- 保存后：每个末梢的枝头垂一根短梗，挂一颗果（r 5.2）；一颗果对应文档的一章

## 文字与悬停
- 树上不画任何文字（轮次标签也已去掉）；轮次和话题只显示在右上角的 meta 里
- 每个节点有一块 r 11 的透明感应区；悬停或点击时弹出一张纸色小卡（#f7f2e8 底，#cfc5b0 边框，带轻阴影，最宽 240）。卡上三行：「第 r 轮 · 话题（· 需复核）」、问题原文、「答：…」或「尚未回答」
- 果梗只绘制、不接收指针事件，避免挡住起点的题目节点；果实保留独立的扩大感应区和键盘入口

## 布局
- 左侧：标题、副标题，以及问题卡（left 56，top 46%，宽 330）
- 右侧：树的区域（左边距 400，其余三边约 20），SVG 用 xMidYMax meet 适配
- 树按全部节点的 x 范围水平居中；28 题时树要接近满高，但不能被裁掉

## 动画
- 每轮生长：树干先长出新的一段，枝按深度依次延迟 0.2 抽出（stroke 抽长，缓动 easeOutCubic）；生长进度 g 从 0 到 1，大约 12 帧（约 1 秒）
- 晕染色块随 g 淡入并放大
- 每答一题，在本地立刻开一朵花，不等 AI
- 一轮提交后，问题卡显示「正在想下一轮的问题…」；60 秒后出提示（还没实现）
- 保存后，果子按顺序以 0.04 的间隔长出，大约 1 秒
